## قالب هر خط

```json
{"messages":[{"role":"system","content":"..."},{"role":"user","content":"..."},{"role":"assistant","content":"..."}]}
```

فقط از سه نام نقش `system` / `user` / `assistant` استفاده می‌شود — بدون `tool`، `developer` یا هر نقش سفارشی. سناریوهای چندمرحله‌ای می‌توانند چند نوبت پیام `assistant` و `user` داشته باشند و مستقیم برای Soup قابل استفاده‌اند.

## قواعد حاکم (بدون تغییر از ابتدا)

1. هر عدد در پاسخ از observation محاسبه می‌شود؛ عدد بیرون از کاتالوگ داده اختراع نمی‌شود.
2. کاتالوگ داده‌ها بسته است و به پیام کاربر چسبیده می‌شود.
3. عدم‌قطعیت صادقانه: در سناریوهای عدم‌قطعیت، پاسخ توصیهٔ قطعی نمی‌دهد.
4. پاسخ نهایی سناریوهای تحلیلی شش‌بخشی است: یافته، شواهد، ریشهٔ اصلی، اثر بر کسب‌وکار، اقدام پیشنهادی، اطمینان و محدودیت‌ها؛ رکوردهای مقدماتیِ هویتی/زبانی استثنای عمدی‌اند.
5. تکراری‌های محتوایی در سطح منبع و سراسری حذف می‌شوند.
